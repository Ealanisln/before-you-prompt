# Changelog

## 1.2 — 2026-08-05

- Multi-client integrations (`integrations/`): OpenAI Codex CLI (skill +
  custom prompt), Gemini CLI (TOML custom command), AGENTS.md snippet for
  Cursor/Zed/Copilot-style tools, and a universal paste-anywhere prompt.
- `install.sh` now offers optional Codex/Gemini installs when those clients
  are detected.
- README: step-by-step usage guide with example session, manual mode, and an
  AI-tool compatibility table (mirrored in Spanish).

## 1.1 — 2026-08-05

- Added OWASP Top 10 (2021) mapping table, OWASP API Security Top 10 note, and
  ASVS level guidance to the security document (both languages).
- Added full English template tree (`en/`) with equivalent ID conventions
  (`US`/`OI`/`TC` ≡ `HU`/`P`/`CP`).
- Skill updated to v1.1: bilingual assets and a language decision gate.

## 1.0 — 2026-08-05

- Initial suite: 13 Spanish templates (user stories, technical spec, API
  contracts, NFRs, security, integration deep-dives, test plan, delivery plan,
  traceability matrix, open-items register, design prompt) plus the
  `planning-suite` Claude Code skill.
