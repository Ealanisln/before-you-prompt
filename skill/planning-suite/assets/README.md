# Planning template / Plantilla de planeación

Reusable project-planning document suite, available in two languages:

- [`es/`](es/README.md) — suite completa en español (IDs: `HU-xx`, `P-xx`, `CP-xx`; responsables `[N]/[TI]/[PROV]`). Empieza por [`es/_GUIA.md`](es/_GUIA.md).
- [`en/`](en/README.md) — full suite in English (IDs: `US-xx`, `OI-xx`, `TC-xx`; owners `[BIZ]/[IT]/[VENDOR]`). Start with [`en/_GUIDE.md`](en/_GUIDE.md).

Pick **one** language per project; the trees are 1:1 equivalents — do not mix them.
Elige **un** idioma por proyecto; los árboles son equivalentes 1:1 — no los mezcles.
